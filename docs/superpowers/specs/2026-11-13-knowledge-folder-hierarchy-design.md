# 知识库文件夹层级设计

日期：2026-11-13  
范围：AgentOS Mock（`dist/agentos`）知识库板块  
状态：待实现

## 背景

知识库当前为扁平表格，仅有类型 Tab 与工序/密级/状态筛选。资料虽有「资料库」元数据字段，但无浏览用文件夹层级。用户需要按文件夹下钻管理资料。

## 目标

- 面包屑下钻浏览：进入文件夹看直接子文件夹 + 本层资料
- 独立文件夹树（与「资料库」属性分离）
- 可建管：新建、重命名、删除空文件夹；上传落到当前文件夹
- 保留现有权限/密级、解析、详情编辑等能力

非目标：拖拽移动、批量移动、文件夹权限单独 ACL、左侧树面板。

## 信息架构

- 根节点「全部资料」：`parentId === null` 的文件夹 + 无 `folderId` / `folderId` 为空的资料
- 进入某文件夹后，列表只显示其**直接子文件夹**与**该层资料**
- 页面内面包屑：`知识库 / 科研报告 / 高炉 …`，可点击任意级返回
- 类型 Tab、搜索、工序/密级/状态筛选作用于当前可见范围
- 搜索非空时：在当前文件夹分支内**递归**匹配资料（含子文件夹），结果行展示所在路径
- `library` 等元数据字段保留，不再作为浏览层级

## 数据模型

### folders

```text
{ id: string, name: string, parentId: string | null }
```

存于 `store.state.folders`，随现有 `localStorage`（`agentos.ironworks.v1`）持久化。

### docs

- 新增可选字段 `folderId: string | null`
- 缺省或空视为根目录

### 种子文件夹（示例，实现时可微调命名）

| id | name | parentId |
|----|------|----------|
| f-report | 科研报告 | null |
| f-report-bf | 高炉 | f-report |
| f-report-sinter | 烧结 | f-report |
| f-topic | 课题库 | null |
| f-drawing | 图纸库 | null |
| f-drawing-bf | 高炉 | f-drawing |
| f-std | 标准库 | null |
| f-expert | 专家经验 | null |

现有 docs 按 `library` / `process` 映射挂到对应 `folderId`（如科研报告库+高炉 → `f-report-bf`；图纸库+高炉 → `f-drawing-bf`；代码库/数据库可挂根或单独文件夹）。

### 迁移

加载 state 时：若无 `folders`，写入种子文件夹，并为缺少 `folderId` 的 docs 按映射规则补齐。不破坏已解析状态与其它字段。

## 界面与交互

### 布局

- 保持现有 page-head、类型 Tab、筛选工具栏、表格
- 工具栏增加「新建文件夹」
- 表格上方或表头区域展示面包屑（与顶栏全局 crumbs 可并存；本设计以页面内路径为准）
- 表体混排：先文件夹行，后资料行

### 文件夹行

- 图标 + 名称 + 子项数量（直接子文件夹数 + 本层可见资料数，受权限过滤）
- 点击整行进入该文件夹
- ⋯ 菜单：重命名、删除
  - 删除仅当空：无子文件夹且无资料（含无权限可见但仍存在的资料时不可删，提示非空）
- 重命名：弹窗改名，同级重名校验

### 资料行

- 列与现有基本一致；搜索递归模式下可增加「路径」列或副标题路径
- 点击打开现有详情抽屉

### 上传

- 写入当前文件夹的 `folderId`
- 弹窗可选目标文件夹（扁平路径下拉，默认当前）

### 编辑资料

- 可改所属文件夹（扁平路径下拉）

### 新建文件夹

- 在当前目录下创建；同级名称唯一（trim 后比较）

## 核心逻辑（视图层）

- `currentFolderId`：`null` 表示根
- `childrenFolders(id)` / `docsInFolder(id)`：直接子项
- `folderPath(id)`：面包屑用祖先链
- `folderLabel(id)`：扁平路径字符串（如 `科研报告 / 高炉`）
- 列表过滤：权限 `P.canView` + Tab/工序/密级/状态；文件夹行本身不过密级，但其计数只计可见资料
- 类型 Tab「全部」时文件夹与资料均显示；非全部 Tab 时：仍显示子文件夹（便于下钻），资料按类型过滤；若需更严，可仅在「全部」显示文件夹——**采用前者**（始终可下钻）

## 不变项

- `policy.canView`、解析进度、上传模拟失败规则
- `library` / `process` / `level` / `acl` 语义
- 对话引擎检索逻辑本期不改为按文件夹过滤（文件夹仅管理浏览；检索仍按现有 docs 全量+权限）

## 测试 / 验收

1. 根目录可见种子一级文件夹；进入后见二级与对应资料
2. 面包屑可逐级返回根
3. 新建文件夹出现在当前层；同级重名被拒绝
4. 重命名后面包屑与列表立即更新并持久化（刷新后仍在）
5. 非空文件夹无法删除；清空后可删
6. 上传资料出现在当前（或所选）文件夹
7. 密级/部门过滤后隐藏资料计数正确；切换演示账号可见性变化
8. 搜索在子树内命中并展示路径
