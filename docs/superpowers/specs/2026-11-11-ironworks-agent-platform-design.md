# 炼铁厂智能体平台设计方案

日期：2026-11-11
状态：方案已确认，待细化页面与接口

## 1. 目标与范围

建设一个厂内私有化部署的智能体平台，用于创建、调试、发布和运营智能体。平台围绕科研技术管理全流程规划 14 个智能体，按 5 类分批上线。

所有智能体都基于第 4 节的平台能力搭建，主要差异在提示词、流程模板和勾选的工具，不需要单独开发后端。其中科研资料助手和调研报告助手是核心场景；一期 4 个智能体的详细流程见第 5 节，各智能体的补充约束见第 6 节。

“默认模型 / 资料范围”沿用 4.4 的规则，用户可在对话中修改；标注“锁定”的智能体只配置内网模型，用户不能切换到外网模型。

| 分类 | 智能体 | 解决的问题 | 勾选的内置工具 | 默认模型 / 资料范围 | 上线批次 |
|---|---|---|---|---|---|
| 资料查询与知识管理 | **科研资料助手**（核心场景） | 炼铁厂科研资料的查询与管理，资料类型包括 PDF、Word、CAD、代码和数据库数据 | 文档检索、图纸检索、代码检索、数据查询、联网搜索、网页读取 | 内网 / 厂内 | 一期（图纸检索、代码检索、数据查询二期接入） |
| 资料查询与知识管理 | 标准规范查询助手 | 查询国家、行业、企业标准条款，对比新旧版本差异，判断工艺或产品是否合规 | 文档检索（标准库入库）、联网搜索、网页读取 | 内网 / 全部 | 二期 |
| 资料查询与知识管理 | 专家经验沉淀助手 | 将专家访谈转写稿、经验笔记整理为结构化知识条目，经确认后入库，供其他智能体检索 | 文档检索、报告导出 | 内网 / 厂内 | 二期 |
| 课题立项与过程管理 | 立项查新助手 | 立项前检索厂内已有课题和外部论文、专利，判断是否重复，生成查新报告 | 文档检索、联网搜索、网页读取、报告导出 | 内网 / 全部 | 一期 |
| 课题立项与过程管理 | 课题申报书助手 | 按厂内模板撰写可行性研究报告和申报书，引用历史课题成果和外部数据 | 文档检索、联网搜索、网页读取、报告导出（模板填充） | 内网 / 全部 | 二期 |
| 课题立项与过程管理 | 结题验收助手 | 汇总课题月报和试验记录，生成结题报告与验收材料，核对任务书指标完成情况 | 文档检索、数据查询（科研管理系统）、报告导出（模板填充） | 内网 / 厂内 | 二期 |
| 研发与技术攻关 | 工艺问题诊断助手 | 炉况异常、烧结矿质量波动、铁水成分偏差等问题出现时，检索历史攻关报告和事故分析，结合生产数据给出排查思路 | 文档检索、数据查询 | 内网 / 厂内 | 二期 |
| 研发与技术攻关 | 试验方案设计助手 | 根据研究目标和历史试验，生成试验方案、参数范围、检测项目和安全注意事项 | 文档检索、联网搜索、网页读取、报告导出 | 内网 / 全部 | 二期 |
| 研发与技术攻关 | 试验数据分析助手 | 查询试验和生产数据，做对比、趋势分析并出图，撰写分析结论 | 数据查询、数据分析、报告导出 | 内网 / 厂内 | 三期 |
| 成果与知识产权 | 专利挖掘与交底书助手 | 从结题报告中找出可申请专利的技术点，检索现有技术，撰写技术交底书 | 文档检索、联网搜索、网页读取、报告导出 | 内网（锁定）/ 全部 | 二期 |
| 成果与知识产权 | 成果与奖项申报助手 | 汇总课题成果和经济效益，生成科技成果鉴定材料、科技进步奖申报书 | 文档检索、报告导出（模板填充） | 内网 / 厂内 | 二期 |
| 成果与知识产权 | 技术总结与论文助手 | 将课题成果整理为技术总结、内部技术报告或论文初稿 | 文档检索、联网搜索、网页读取、报告导出 | 内网 / 全部 | 二期 |
| 调研与技术情报 | **调研报告助手**（核心场景） | 根据互联网公开资料撰写调研报告，可结合厂内资料 | 联网搜索、网页读取、文档检索、报告导出 | 外网 / 公开 | 一期 |
| 调研与技术情报 | 技术情报简报助手 | 跟踪同行企业、科研院所的技术动态、专利和论文，生成月度技术情报简报 | 联网搜索、网页读取、报告导出 | 外网 / 公开 | 一期手动生成；三期接入定时运行 |

平台闭环只覆盖「发布 → 试用 → 上线 → 会话记录与反馈 → 导出」。评测和优化在线下人工完成，结果通过发布新版本回到平台。

**不在本期范围**：在线评测、自动评估器、自动优化、CAD 图纸内容理解、多租户 SaaS 运营。

## 2. 关键约束与决策

| 编号 | 决策 | 原因 |
|---|---|---|
| D1 | 厂内私有化部署，调研报告经受控出口访问互联网和外部大模型 | 科研资料不出内网，报告场景需要公开信息 |
| D2 | 自建平台层，底层采用开源引擎 | 权限、多格式解析、内外网隔离必须可控；解析、检索、推理复用成熟组件 |
| D3 | CAD 只做文件管理和简单检索，不理解图纸内容 | 需求是“图纸管得住、找得到”，不需要图纸语义 |
| D4 | 用户可自选模型（内网 / 外网）和资料范围（公开 / 厂内 / 全部）；平台按密级限制哪些厂内资料可发给外网模型 | 兼顾使用灵活性与保密要求，机密资料不出网 |
| D5 | 数据库数据不进入向量库，通过只读 SQL 实时查询 | 结构化数据向量化后精度差，且数据会过期 |
| D6 | 产品交互沿用现有 AgentOS 的智能体工坊与线上会话设计 | 减少设计成本，保持产品一致 |
| D7 | 多格式资料的解析与检索以系统内置工具提供，智能体按需勾选 | 资料能力统一封装，权限、密级和调用记录在工具内统一处理；新智能体无需重复配置 |

## 3. 整体架构

平台分为五层，统一治理能力贯穿运行时和能力服务。

| 层级 | 组成 | 职责 |
|---|---|---|
| 接入层 | 智能体门户、智能体工坊、管理控制台 | 终端用户对话；配置人员生产智能体；管理员管理资料、权限和会话 |
| 场景智能体 | 第 1 节总表中的 14 个智能体、用户自建智能体 | 面向具体业务的智能体实例 |
| 智能体运行时 | 编排引擎、版本与发布、会话记录、定时运行 | 执行提示词、工作流和多步规划；管理版本状态；记录全量会话证据；按计划自动运行智能体 |
| 能力服务 | 系统内置工具、知识库服务、模型网关 | 面向智能体提供资料检索、联网和导出能力；资料存储与索引；模型路由、密级拦截与审计 |
| 数据层 | 对象存储、关系库、向量库与全文检索、厂内业务数据库 | 原始文件、元数据与会话、检索索引、只读业务数据 |
| 统一治理 | 组织与用户、角色权限、文档级权限与密级、操作审计、监控 | 跨层的安全与可观测能力 |

各单元通过接口通信，相互独立：

- **系统内置工具** 是智能体访问资料和外部能力的唯一方式，按统一的工具协议注册；智能体按配置引用，不直接访问数据源。
- **知识库服务** 只负责资料存储、入库处理和索引，供内置工具调用，不感知智能体。
- **模型网关** 是所有模型调用的唯一入口，智能体不直接连接模型。
- **会话记录** 由运行时在每轮执行后写入，不依赖具体智能体实现。

## 4. 功能模块

### 4.1 智能体工坊

- **创建**：选择模板（问答型、报告型、工作流型），配置角色提示词、可用模型、内置工具及其参数、开场白和推荐问题。
- **调试**：右侧对话预览，展示每次内置工具调用的入参与返回、引用来源、耗时和 Token。
- **版本**：每次发布保存完整配置快照，可查看历史版本和回滚；会话记录绑定版本号。

### 4.2 知识库与资料管理

- **入库**：单个上传、批量导入、共享目录定时同步、Git 仓库接入。
- **元数据**：课题、工序（高炉、烧结、焦化、球团等）、年份、作者、密级、资料类型；支持自定义字段。
- **权限**：组织角色 + 文档级权限 + 密级。检索时先按权限过滤再召回，越权片段不会进入模型上下文。
- **管理**：分类、标签、版本、去重、失效标记、解析状态与失败重试。
- **与工具的关系**：资料入库后，由对应内置工具的入库处理完成解析和索引（见 4.3）；智能体只能通过内置工具检索资料。

### 4.3 系统内置工具

多格式资料的解析与检索、联网检索和报告导出，全部以系统内置工具提供。智能体在工坊中勾选需要的工具，运行时由模型按需调用。一期只提供内置工具，不开放自定义工具接入。

**统一约定**

- **身份与权限**：每次调用携带当前用户身份，工具内部先按文档级权限和密级过滤，再返回结果。
- **返回格式**：结果统一带来源定位（文件与页码、图号、代码文件与行号、数据表、网页地址）和资料密级，供引用标注和出网策略判断。
- **调用记录**：入参、返回摘要、耗时和错误写入会话记录。
- **可配置项**：配置人员在工坊中只能设置工具参数（如限定资料库、返回条数），不能修改工具逻辑。

**工具清单**

| 工具 | 适用资料 | 入库处理（资料上传或同步时自动执行） | 调用能力 |
|---|---|---|---|
| 文档检索 | PDF / Word | 版面解析，扫描件 OCR，识别表格和公式，按章节切片，保留页码 | 向量 + 关键词 + 元数据混合检索，重排后返回片段与页码 |
| 图纸检索 | CAD（DWG / DXF） | 生成缩略图；尽量自动读取标题栏字段（图号、名称、版本、设计人、日期），读取不到时人工补录 | 按文件名、图号、标题栏字段、标签和所属课题检索，返回图纸文件与预览；不理解图纸内容 |
| 代码检索 | 代码 | 按仓库同步，按函数、类切片，保留文件路径与行号 | 代码语义检索 + 关键词检索，返回代码片段与行号 |
| 数据查询 | 厂内数据库、科研管理系统 | 不入库；维护数据字典（表、字段、含义、单位、示例值） | 生成只读 SQL，校验后执行，返回表格或图表 |
| 数据分析 | 数据查询返回的结果 | 无 | 在内网沙箱中执行统计计算和绘图，返回分析结果与图表；不能访问网络和数据源 |
| 联网搜索 | 互联网 | 无 | 发送检索关键词，返回网页标题、摘要和地址 |
| 网页读取 | 互联网 | 无 | 抓取网页并提取正文 |
| 报告导出 | 无 | 管理员上传 Word 模板并标注章节占位 | 将对话内容或报告生成 Word / Markdown 文件；支持按模板章节填充 |

图纸检索的标题栏读取和缩略图生成需要评估 DWG 解析组件的授权方式；无法授权时，先将 DWG 批量转换为 DXF，或只依赖人工补录的字段。

数据查询的安全要求：

- 使用独立只读账号，只开放数据字典中登记的表和字段。
- 执行前校验 SQL，只允许查询语句，并限制返回行数和执行时长。
- 记录每次 SQL、执行人、结果行数和耗时。

数据分析的安全要求：

- 沙箱禁止访问网络、文件系统和数据库，只能处理本轮数据查询返回的结果。
- 限制单次执行时长和内存，超限即终止。
- 记录每次执行的代码、输入数据摘要和输出。

### 4.4 模型与资料范围选择

**用户侧选择**：对话输入框旁提供两个选择项。

- 模型：内网模型或外网模型。可选项由智能体配置决定，配置人员为每个智能体设置可用模型和默认模型；只配置内网模型时，用户无法切换到外网模型（即“锁定内网模型”）。
- 资料范围：公开资料（互联网）、厂内资料（知识库与业务数据库）、全部。

资料范围决定本轮对话可调用哪些内置工具，智能体未勾选的工具不受资料范围影响，始终不可用：

| 资料范围 | 可调用的工具 |
|---|---|
| 公开资料 | 联网搜索、网页读取 |
| 厂内资料 | 文档检索、图纸检索、代码检索、数据查询 |
| 全部 | 以上全部 |

报告导出和数据分析不直接读取资料，不受资料范围限制。

**平台侧约束（出网策略）**：外网模型和厂内资料组合使用时，按资料密级决定能否发送。

| 资料密级 | 发给内网模型 | 发给外网模型 |
|---|---|---|
| 公开 | 允许 | 允许 |
| 内部 | 允许 | 由管理员按组织配置“允许”或“禁止”，默认禁止 |
| 秘密及以上 | 允许 | 禁止，任何配置都不能放开 |

- 用户选择“外网模型 + 厂内资料”时，对话前弹出一次确认，说明哪些资料会发送到外网。
- 被策略拦截的片段不进入外网模型上下文；回答中提示“部分资料因密级限制未使用”，并建议切换内网模型。
- 每次对话记录所选模型、资料范围、实际发出的资料清单。

### 4.5 模型网关

- 统一接入内网本地模型和外部大模型，执行 4.4 的出网策略。
- 出网请求先经过密级标签检查和敏感词拦截，命中后拒绝并记录。
- 记录调用方、智能体版本、模型、Token、耗时；支持按用户和智能体限流。

### 4.6 会话与运营

- 会话列表：按智能体、版本、用户、时间、反馈筛选。
- 会话详情：所选模型与资料范围、消息、内置工具调用（入参与返回）、引用、耗时、Token、错误信息。
- 用户反馈：点赞、点踩、文字反馈，以及对某条引用的“来源有误”标记。
- 导出：按筛选条件导出 Excel 或 JSONL，供线下评测使用。

### 4.7 定时运行

- 配置人员为智能体设置运行计划（每天、每周、每月）和固定输入，例如“汇总本月高炉炼铁技术动态”。
- 每次运行以计划创建者的身份和权限执行，产生一条独立会话，记录方式与人工对话一致。
- 运行结果推送给订阅人（站内消息，可选邮件），附带导出文件。
- 运行失败时通知计划创建者，不自动重试。

## 5. 一期智能体流程

以下为一期 4 个智能体的详细流程，默认模型、资料范围和勾选的工具见第 1 节智能体总表。二期、三期智能体的流程在细化阶段按同样方式补充。

### 5.1 科研资料助手

一期先勾选文档检索、联网搜索和网页读取，图纸检索、代码检索、数据查询在二期接入。

1. 用户提问，可选限定工序、年份、资料类型。
2. 模型根据问题调用内置工具：查报告用文档检索，找图纸用图纸检索，查程序用代码检索，查数据用数据查询；资料范围包含公开资料时可同时联网搜索。工具内部按用户权限过滤。
3. 按所选模型和出网策略生成回答，每个结论标注引用来源，可跳转到原文页码、图纸预览、代码行或网页。
4. 检索不到可靠依据时，明确告知“未找到相关资料”，不编造答案。

另提供“资料检索”模式：直接调用文档检索或图纸检索，返回文件列表、摘要和预览，适合查找图纸或报告原件。

### 5.2 调研报告助手

1. 用户输入主题、用途和篇幅要求，选择模型和资料范围。
2. 生成报告大纲，用户确认或修改。
3. 按章节多轮检索：公开资料调用联网搜索和网页读取，厂内资料调用文档检索。
4. 来源筛选与评级：发布机构、发布时间、可信度；低可信来源标记后由用户决定是否采用。
5. 分章节撰写，正文标注引用并区分“公开来源”和“厂内资料”，文末列出参考来源。
6. 调用报告导出生成 Word。使用了厂内资料的报告，导出时带上最高引用资料的密级标识。

联网搜索只发送检索关键词，不发送厂内资料内容；厂内资料能否进入外网模型由出网策略决定。

### 5.3 立项查新助手

1. 用户输入拟立项课题的名称、研究内容和预期目标，或上传立项建议书。
2. 智能体提炼 3～8 个查新要点（关键技术点），并生成对应检索关键词，用户确认或修改后再检索。
3. 厂内查重：调用文档检索，在历史立项书、结题报告、技术总结中查找相似课题，列出课题名称、年份、承担部门和相似点。
4. 外部查新：调用联网搜索和网页读取，检索公开论文、专利、标准和行业报道，提取标题、来源、发表时间和摘要。
5. 逐要点对比：每个查新要点给出“厂内已有 / 外部已有 / 未发现相同成果”的结论，并附依据和引用。
6. 生成查新报告：包括查新目的、查新要点、检索范围与关键词、相似成果清单、对比分析和查新结论（建议立项 / 建议调整研究内容 / 存在重复），调用报告导出生成 Word。

查新结论仅作为内部立项参考，不替代正式科技查新机构出具的查新报告。拟立项内容属于未公开信息，默认使用内网模型；联网检索只发送用户确认过的关键词。

### 5.4 技术情报简报助手（手动版）

1. 用户输入跟踪主题（如高炉低碳冶炼、氢冶金、烧结烟气治理）、关注对象（同行企业、科研院所）和时间范围，时间范围默认为上一个自然月。
2. 智能体按主题和关注对象生成检索词组，调用联网搜索，检索新闻、论文、专利和政策标准，并限定在时间范围内。
3. 调用网页读取提取正文；同一事件的多个来源合并为一条，剔除超出时间范围或与主题无关的内容。
4. 分类整理为技术动态、专利、论文、政策标准、行业事件；每条包含摘要、来源链接、发布时间，以及对本厂的关注度（高 / 中 / 低）和简要说明。
5. 生成简报：本期要点（3～5 条）在前，分类条目在后，调用报告导出生成 Word。
6. 用户可在对话中追问某条情报的细节，或要求调整分类和关注度后重新导出。

一期由用户手动发起；三期接入定时运行（见 4.7）后，按相同输入每月自动生成并推送给订阅人。默认资料范围为公开资料，不涉及厂内资料。

## 6. 智能体补充约束与批次安排

### 6.1 补充约束

| 智能体 | 约束 | 原因 |
|---|---|---|
| 专利挖掘与交底书助手 | 锁定内网模型，用户不能切换到外网模型 | 交底书涉及未公开技术方案，泄露会导致丧失新颖性 |
| 工艺问题诊断助手 | 只提供排查思路和历史依据，不直接给出操作指令；回答中注明“需由工艺人员确认后执行” | 生产操作存在安全风险，决策责任在工艺人员 |
| 专家经验沉淀助手 | 条目入库前必须经专家本人或指定审核人确认，未确认的条目不进入文档检索范围 | 避免未经核实的经验被其他智能体引用 |

### 6.2 批次安排原则

- **一期**：科研资料助手、调研报告助手两个核心场景，以及立项查新、技术情报简报（手动版）。后两个只依赖一期内置工具，且与核心场景的能力高度复用。
- **二期**：依赖模板填充、数据查询，或需要先完成标准库、专家经验等资料入库的智能体；成果与知识产权类的 3 个智能体整体放在二期。其中试验方案设计、专利挖掘与交底书、技术总结与论文在技术上只需一期工具，为控制一期范围放到二期。
- **三期**：依赖数据分析工具或定时运行的智能体。

## 7. 上线闭环

| 状态 | 可见范围 | 说明 |
|---|---|---|
| 草稿 | 创建者 | 配置与调试 |
| 试用 | 指定试用人员 | 收集早期会话与反馈 |
| 上线 | 按组织或角色开放 | 正式使用 |
| 下线 | 不可对话 | 保留历史会话与导出 |

线下评测与优化后发布新版本，新版本先进入试用，再切换为上线。会话记录始终绑定产生它的版本号，用于线下对比优化前后的效果。

## 8. 部署方案

### 8.1 网络分区

- **内网区**：应用服务（门户、工坊、运行时、系统内置工具、知识库、模型网关）、数据分析沙箱、本地模型推理、数据组件、厂内科研数据库与科研管理系统只读连接。
- **出口隔离区**：出口网关，负责域名白名单、密级拦截、请求审计。
- **互联网**：搜索引擎、目标网页、外部大模型。

数据流规则：

- 秘密及以上资料只进入内网模型；“内部”密级资料能否发往外网模型按管理员配置执行，默认禁止。
- 联网搜索请求只携带检索关键词。
- 所有出网请求在出口网关全量记录，包括发出的资料清单。

### 8.2 技术选型参考

| 类别 | 选型 |
|---|---|
| 模型推理 | vLLM |
| 内网大模型 | Qwen 或 DeepSeek 系列 32B～70B 级别 |
| 向量与重排 | bge-m3 + bge-reranker |
| 文档解析 | MinerU 类版面解析工具 + OCR |
| 向量库 | Milvus |
| 全文检索 | Elasticsearch |
| 关系库与对象存储 | PostgreSQL、MinIO |
| 数据分析沙箱 | 隔离容器内的 Python 运行环境，预装常用统计与绘图库 |
| 部署 | 试点使用 Docker Compose，生产迁移到 Kubernetes |

### 8.3 规模建议

- **试点（几十人）**：1 台 4～8 卡 GPU 推理服务器，2～3 台应用与数据服务器。
- **生产**：推理服务器按并发扩容，应用层多副本，数据组件主备。
- 具体卡型取决于是否要求国产算力，以及高峰并发人数，在试点阶段压测后确定。

## 9. 异常处理

| 场景 | 处理方式 |
|---|---|
| 文件解析失败 | 标记失败原因，支持重试；不影响同批次其他文件 |
| 内置工具调用失败或超时 | 记录错误，模型告知用户该工具暂不可用，并基于其他工具的结果继续回答 |
| 检索无结果 | 告知未找到资料，给出调整筛选条件的建议 |
| SQL 校验不通过或超时 | 拒绝执行，向用户说明原因，记录审计日志 |
| 出网请求被拦截 | 告知用户哪些资料因密级未使用，建议切换内网模型，记录拦截原因 |
| 外部模型不可用 | 提示切换到内网模型继续 |
| 联网搜索不可用 | 提示只能使用厂内资料，用户确认后继续 |
| 内网模型过载 | 排队并显示等待状态，超时后提示重试 |
| 数据分析执行超时或报错 | 终止沙箱执行，返回错误信息，模型改用表格形式呈现原始数据 |
| 定时运行失败 | 通知计划创建者，保留失败会话，不自动重试 |
| 模板章节无法填充 | 在导出文件中保留空章节并标注“待补充”，提示用户手动完善 |

## 10. 验证方式

- **功能验证**：每个模块按验收清单逐项测试，覆盖每个内置工具的入库处理与调用、权限过滤、模型与资料范围的全部组合、版本发布与回滚、会话导出。
- **安全验证**：构造越权查询、秘密级资料发往外网模型、非只读 SQL、数据分析沙箱访问网络等用例，确认全部被拦截；验证“内部”密级在允许和禁止两种配置下的行为；验证锁定内网模型的智能体无法切换到外网模型。
- **效果验证**：试用期导出会话，线下人工评测回答准确率和引用正确率，作为是否上线的依据。

## 11. 分期计划

| 阶段 | 周期 | 平台能力 | 智能体 |
|---|---|---|---|
